\doxysubsection{Detailed Description}
Provides the interface for running register allocation algorithms. 

This module defines the main entry points for performing register allocation based on live ranges input and algorithm settings. It builds webs from live ranges and invokes the appropriate allocation strategy (basic, spilling, splitting, or free).
