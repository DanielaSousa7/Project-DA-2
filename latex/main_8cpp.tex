\doxysubsection{Detailed Description}
Entry point of the register allocation tool. 

Decides between batch mode and interactive mode based on command line arguments.
\begin{DoxyItemize}
\item If called with "{}-\/b ranges.\+txt registers.\+txt output.\+txt"{}, runs batch mode.
\item Otherwise, launches the interactive menu. 
\end{DoxyItemize}
