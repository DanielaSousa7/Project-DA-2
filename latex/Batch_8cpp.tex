Executes batch mode\+: parse, allocate, output. 

Runs the allocation tool in batch mode.

Steps\+:
\begin{DoxyEnumerate}
\item Parse input files.
\item If parsing errors occur, report and abort.
\item Print summary of loaded data to console.
\item Run register allocation.
\item Write results to output file.
\end{DoxyEnumerate}
