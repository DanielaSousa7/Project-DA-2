Detailed Description

Interface for batch-mode execution.

Provides a function to run the register allocation tool in non-interactive batch mode, reading input files and writing the output to a specified file.

Runs the allocation tool in batch mode.

Parses the live ranges file and registers file, performs register allocation according to the algorithm specified in the registers file, and writes the result to the given output file. Errors are printed to standard error.

Parameters
rangesFilePath to the file containing variable live ranges.
registersFilePath to the file containing register count and algorithm.
outputFilePath where the allocation result will be written.

@complexity O(F + A) where F is the size of input files (parsing) and A is the complexity of the selected allocation algorithm. Parsing is linear in the number of lines.

Runs the allocation tool in batch mode.

Steps:

  1. Parse input files.
  2. If parsing errors occur, report and abort.
  3. Print summary of loaded data to console.
  4. Run register allocation.
  5. Write results to output file.
Parameters
rangesFileLive ranges input file.
registersFileRegister settings input file.
outputFileDestination file for allocation mapping.

@complexity O(n + m + A) where: n = total lines in ranges file, m = lines in registers file, A = complexity of the allocation algorithm (see Allocation.cpp). All file I/O is linear in input size.
