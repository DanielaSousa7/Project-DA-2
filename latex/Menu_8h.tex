\doxysubsection{Detailed Description}
Interactive menu functions for the register allocation tool. 

Provides a console-\/based user interface to load input files, browse data, run register allocation, and generate output. The menu supports both interactive mode (via \doxylink{Menu_8h_a8396c50bf544009fb2fc4907b00cbad3}{main\+Menu()}) and batch mode (handled separately).
