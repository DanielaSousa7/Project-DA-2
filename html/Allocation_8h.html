Detailed Description

Provides the interface for running register allocation algorithms.

This module defines the main entry points for performing register allocation based on live ranges input and algorithm settings. It builds webs from live ranges and invokes the appropriate allocation strategy (basic, spilling, splitting, or free).

Selects and executes the allocation algorithm according to settings.

Dispatches to one of the concrete allocation implementations:

  • "basic" -> basicRegisterAllocation()
  • "spilling" -> spillingRegisterAllocation()
  • "splitting" -> splittingRegisterAllocation()
  • "free" -> freeRegisterAllocation() Defaults to basic if algorithm name is unrecognised.
Parameters
websVector of webs built from live ranges.
settingsRegister settings (number of registers, algorithm name, optional parameter for spilling/splitting).
Returns
AllocationResult with assignment and success status.

@complexity Depends on the dispatched algorithm:

  • Basic: O(N^2) for greedy coloring on N nodes.
  • Spilling: O(K * N^2) where K is the spilling limit.
  • Splitting: O(N^3) in worst case due to web splitting and re-coloring.
  • Free: User-defined; documented separately.
